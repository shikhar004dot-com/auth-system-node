# Authentication System (Node.js + Passport)

This project is a user authentication system built using Node.js and Express. It includes secure login and registration with validation and session handling.

## Features
- User Registration & Login
- Password hashing using bcrypt
- Authentication using Passport.js
- Session management with express-session
- Server-side validation using JOI
- Client-side validation using Bootstrap
- Clean UI with responsive design

## Tech Stack
- Node.js
- Express.js
- MongoDB (Mongoose)
- Passport.js
- JOI
- Bootstrap
